# Antarctic Navigation Prototype — Prerequisites

## Accounts

The team needs access to:

* GitHub
* Copernicus Marine
* NASA Earthdata
* ECMWF Climate Data Store
* Global Fishing Watch API

## Software

Install:

* Python 3.10+
* Node.js LTS
* Git
* VS Code
* Docker Desktop

## Python libraries

The backend/model environment will use:

* fastapi
* uvicorn
* pydantic
* numpy
* scipy
* pandas
* xarray
* netCDF4
* pyproj
* rasterio
* rioxarray
* shapely
* scikit-image
* opendrift
* scikit-learn
* onnxruntime
* networkx
* copernicusmarine
* earthaccess
* cdsapi
* pynmea2
* pyserial
* numba

## Frontend libraries

The frontend will use:

* React
* React DOM
* Tailwind CSS
* MapLibre/Mapbox
* react-map-gl
* deck.gl
* React Three Fiber
* socket.io-client

## Project data

The team needs cached demo data for:

* Sea ice
* Ocean currents
* SST
* Wind
* Waves
* Iceberg tracks
* Bathymetry
* AUV/sonar
* AIS

## Important

Do not commit:

* API keys
* passwords
* `.env` files
* huge raw datasets
* virtual environments
* `node_modules`
* unnecessary generated files
